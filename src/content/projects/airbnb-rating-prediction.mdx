Machine Learning module assignment: predict an Airbnb listing's rating from its written reviews and other listing information.

I tried two approaches. The first used NLP features from the reviews alone, comparing linear, random forest, ridge and lasso regression; ridge regression did best. Because almost all real ratings sit between 4.0 and 5.0, the signal was weak: a root mean square error of 0.43 against 0.78 for a dummy baseline. It was a useful lesson in how much the data limits the model.

## Context

A Trinity College group project, six of us, to build and deploy a HoloLens app using the Mixed Reality Toolkit, with four Microsoft engineers acting as clients.

## Features

- **Chess** against an AI opponent backed by a REST API over a database of more than 5 billion positions from top players' games.
- **Jenga:** point and click to remove blocks without toppling the tower.
- **Tower of Hanoi** with 3, 5 or 7 disks, using pinch-and-drag.

The games share a hand-tracking and gaze interaction layer built on the Mixed Reality Toolkit: a holographic object can be looked at, air-tapped and dragged, and has to behave sensibly when a person walks around it rather than moving a mouse.

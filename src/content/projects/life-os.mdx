## What I built

- **Integrations**: a FastAPI backend with a router per service: Google Calendar and Gmail, Stagecoach bus arrivals with a live map, Garmin Connect activity and sleep, Monzo balance history, Home Assistant lights and sensors, Spotify playback, weather, and MOT / tax / service reminders for the car.
- **Frontend**: a Next.js and React dashboard with Recharts graphs. Widgets are lazy-loaded, which cut the initial bundle from about 800 KB to 250 KB and load time from 3–5 s to 1–2 s.
- **Data**: SQLModel on SQLite for things the APIs don't store, like plant watering schedules and car maintenance.
- **Deployment**: a GitHub Actions workflow on a self-hosted runner builds the frontend, builds the Docker images and redeploys them on my home server on every push to `main`. Remote access is set up through a Cloudflare Tunnel.

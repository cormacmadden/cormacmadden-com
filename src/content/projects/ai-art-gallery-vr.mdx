## Context

A three-month group project (8 people) for the Software Engineering module of the MSc in Augmented and Virtual Reality, run with agile practices. The app has VR and desktop versions.

## What I built

- 3D modelling of the gallery map and game objects
- Multiplayer with Unity Gaming Services
- OpenAI integration for AI art generation
- Menu design and implementation
- Basic drawing on canvases

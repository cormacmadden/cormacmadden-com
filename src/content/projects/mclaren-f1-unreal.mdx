## Context

A real-time visualisation of the McLaren F1 built in Unreal Engine 5, set up as a configurator: the same car can be switched between paint finishes and environments, and shot either path-traced or with deferred lighting for real-time playback.

## What I built

- The car set up in Unreal Engine 5, exterior and interior, down to the gold-foil engine bay and the central driving seat.
- Paint and environment configurations that can be switched on the same scene.
- A set of stills rendered from the engine, both path-traced and deferred-lit.
